By default the A command uses a locally simulated schedule. Connect either (or both) of the providers below for real airline data instead. Results are cached locally for 24h per route/date/currency, so repeat searches don't burn quota twice.

1. SEARCHAPI.IO - GOOGLE FLIGHTS (tried first - free tier: 100 total requests, no card)
2. APIFY - MULTI-SOURCE FARE SCRAPER (long-term backstop - pay-per-use, ~$0.0003/search, no card required to start)

Used automatically once SearchAPI's free requests run out (or if only this is configured). New accounts get free monthly platform credit that alone covers thousands of casual searches.
